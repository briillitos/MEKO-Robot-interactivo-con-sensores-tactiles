**Equipo:** 

Daniela Toríz García
Abril Pérez Martínez
Andrés Mejia Gutiérrez

## Problema
Qué pasa hoy.

## Usuario
A quién le pasa.

## Sensa / Responde
- Mediante un sensor táctil detectará cuando una persona toca al robot.
- Dependiendo de la interacción, MEKO mostrará distintos estados de ánimo, utilizando la pantalla OLED para representar sus ojos, luces LED para expresar cambios de estado y un sumbador para emitir sonidos.

## Fabricación
Impresión en 3D del cuerpo y cabeza del robot + corte láser de una caja de base para el mismo

## Nivel
